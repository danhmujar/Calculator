# Project: Calculator Efficiency Refactor

## Context
The project is a client-side calculator (Scientific + Percentage) built with Vanilla JavaScript, Vite, and external math libraries (Math.js, MathLive). It follows a 3-tier architecture (Presentation, Application, Data).

## Goals
- **Primary:** Optimize the codebase for efficiency (performance, size, maintainability).
- **Constraint:** Logic and UI must remain unchanged.

## Brand/UI
- Preserve existing UI (no visual changes).

## Research Areas
- Performance optimization techniques for Vanilla JS/DOM interactions.
- Bundle size reduction (Vite, CDN usage).
- Best practices for lazy-loading and dependency management in calculators.
