**Output:** A themed blur effect where the colors are dynamically controlled by the CSS.

<task type="auto">
  <name>Task 1: Create CSS Theme Bridge Module</name>
  <files>
    - "services/theme.js"
  </files>
  <action>
Create a new module at `services/theme.js`. This module will export a function, `getThemeUniforms()`, that reads CSS custom properties (e.g., `--aurora-color-1`) from the DOM using `getComputedStyle(document.documentElement)`.

Crucially, the implementation must `.trim()` the returned string values to prevent parsing errors (Pitfall 2) and then convert the hex color strings into normalized `[r, g, b]` float arrays suitable for WebGL uniforms. This task fulfills D-05 and D-06. We will NOT add a script tag to `index.html` as the project uses ES modules via Vite; instead, we will import this module directly where needed.
  </action>
  <verify>
    <automated>test -f services/theme.js && grep "getThemeUniforms" services/theme.js</automated>
  </verify>
  <done>
A `services/theme.js` module exists and correctly exports theme data read live from the page's CSS.
  </done>
</task>

<task type="auto">
  <name>Task 2: Integrate Theme Uniforms into WebGL Renderer</name>
  <files>
    - "ui/webgl/renderer.js"
    - "ui/webgl/shaders/primitive.frag"
  </files>
  <action>
First, modify `ui/webgl/shaders/primitive.frag` to accept the new theme colors. Add the necessary `uniform vec3` declarations (e.g., `uAuroraColor1`, `uAuroraColor2`). In the shader's `main()` function, use these uniforms to colorize the final output of the blur passes.

Next, modify `ui/webgl/renderer.js`. Import the `getThemeUniforms` function from `services/theme.js`. In the render loop, call this function, retrieve the uniform locations for the new color uniforms, and pass the parsed color values to the shader program using `gl.uniform3fv`.
  </action>
