<task type="auto">
  <name>Task 1: Implement Renderer Resize Logic</name>
  <files>
    - "ui/webgl/renderer.js"
  </files>
  <action>
In `ui/webgl/renderer.js`, create and attach a `ResizeObserver` to the main canvas container element. The observer's callback function must execute the following sequence of actions to ensure correct rendering after a resize event:

1.  Update the `width` and `height` attributes of the `<canvas>` element to match the new dimensions.
2.  Call `gl.viewport()` with the new dimensions to inform WebGL of the new drawing area.
3.  Destroy the old FBOs and their attached textures, then recreate them at the new (downscaled) resolution. Use a constant downscaling factor (e.g., 4) that is shared between initial setup and resize logic to ensure consistency.

**Important:** Ensure that the `ResizeObserver` correctly detects changes in the main container's size when the scientific mode is toggled, as this expansion changes the DOM layout and requires a WebGL resize pass.

This implementation directly fulfills decision D-07 and requirement UI-SYNC-01.
  </action>
