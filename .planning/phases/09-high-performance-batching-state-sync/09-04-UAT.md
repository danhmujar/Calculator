# UAT: 09-04 — GPU-Side Animation Interpolation

**Phase:** 09 - High-Performance Batching & State Sync
**Focus:** Offloading UI transitions to the GPU.

## Context
Confirm that UI animations (position, size, color) are correctly interpolated on the GPU, providing smooth transitions during layout shifts (e.g., sidebar opening, mode switching).

- [ ] **TC-09-04-01**: Sidebar Transition Smoothness
- [ ] **TC-09-04-02**: Scientific Mode Expansion Animation
- [ ] **TC-09-04-03**: Mid-Animation Target Update (Seamlessness)

## Test Cases

### TC-09-04-01: Sidebar Transition Smoothness
**Goal**: Verify that opening/closing the sidebar triggers a smooth GPU-interpolated transition without CPU-side layout jumps.
**Steps**:
1. Open the calculator.
2. Toggle the sidebar (click the menu/burger icon).
3. Observe the transition of the sidebar and the main content area.
**Expected Result**: The sidebar slides in/out smoothly. No stuttering or immediate jumps in position.

### TC-09-04-02: Scientific Mode Expansion Animation
**Goal**: Verify that switching between Standard and Scientific modes animates the layout change.
**Steps**:
1. Start in Standard Mode.
2. Toggle Scientific Mode (e.g., swipe or button click if available).
3. Observe the expansion/contraction of the button grid.
**Expected Result**: Buttons animate to their new positions and sizes smoothly.

### TC-09-04-03: Mid-Animation Target Update (Seamlessness)
**Goal**: Verify that reversing or changing an animation target mid-flight does not cause a visual "pop" or jump.
**Steps**:
1. Trigger a slow transition (e.g., sidebar).
2. Quickly toggle it back before the animation finishes.
**Expected Result**: The animation reverses smoothly from its current position, not from the original start or end point.

### TC-09-04-04: Opacity/Color Fading during Transitions
**Goal**: Verify that elements fading in/out (like new buttons or scientific labels) interpolate their color/alpha on the GPU.
**Steps**:
1. Perform an action that causes elements to appear/disappear (e.g., mode toggle).
2. Watch for color/opacity changes.
**Expected Result**: Elements fade in/out smoothly rather than appearing/disappearing instantly.
