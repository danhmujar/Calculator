# Plan: 09-02-PLAN.md — WebGL 2.0 UBO & Global Uniforms

**Phase:** 09 - High-Performance Batching & State Sync
**Focus:** Shared shader state using Uniform Buffer Objects (UBOs).

## Goal
Implement a centralized global state buffer for WebGL shaders to share time, resolution, DPR, and scroll data, reducing CPU-to-GPU uniform overhead.

## Requirements
- **REQ-WGL-05**: Efficient rendering for 100+ items.

## Success Criteria
1.  **UBO Creation**: A single WebGL buffer is initialized for global uniforms.
2.  **std140 Binding**: Global state follows the `std140` memory layout with correct padding.
3.  **Shader Linkage**: All primitive and text shaders bind to the `GlobalState` UBO at index 0.
4.  **Verifiability**: Changing `u_time` or `u_scroll` in the UBO reflects in all shaders simultaneously.

## Technical Strategy
-   Define a `GlobalState` block in GLSL.
-   Implement `ui/webgl/context.js` helper to initialize and bind UBOs.
-   Use `uniformBlockBinding` and `bindBufferBase` for UBO management.
-   Update `ui/renderer.js` to update the UBO once per frame.

## Tasks
- [ ] Define `GlobalState` struct in `ui/webgl/shaders.js`. <!-- id: 0 -->
- [ ] Implement UBO creation and update logic in `ui/webgl/buffers.js`. <!-- id: 1 -->
- [ ] Update `ui/renderer.js` to populate `GlobalState` buffer each frame. <!-- id: 2 -->
- [ ] Link `GlobalState` to all active programs in `ui/webgl/shaders.js`. <!-- id: 3 -->

## Verification Plan

- **Manual**: Use Spector.js to inspect the Uniform Buffer and confirm it contains the correct values.
