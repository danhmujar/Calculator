# UAT: 09-03-UAT.md — Instanced Batch Rendering

**Phase:** 09 - High-Performance Batching & State Sync
**Plan:** 09-03
**Status:** ✅ PASSED

## Test Overview
Verification of hardware instancing for UI primitives and text. The goal is to ensure that multiple elements (rectangles and glyphs) are rendered in a single WebGL draw call.

## Test Cases

### 1. WebGL 2.0 Availability
- **Goal**: Confirm the application successfully initializes a WebGL 2.0 context.
- **Method**: Check `canvas.getContext('webgl2')` via Playwright.
- **Result**: ✅ PASS
- **Evidence**: Automated test `tests/batch.spec.js` confirms context availability.

### 2. Instanced Draw Call Reduction
- **Goal**: Verify that rendering multiple UI elements results in exactly 1 instanced draw call.
- **Method**: 
    1. Hook `gl.drawArraysInstanced` in the browser.
    2. Trigger a render pass with 3 elements (1 rect, 2 glyphs).
    3. Assert `drawCount === 1` and `totalInstances === 3`.
- **Result**: ✅ PASS
- **Evidence**: 
    - `BROWSER: WebGLRenderer: Pushed instances: 3`
    - Playwright test `Instanced rendering reduces draw calls` passed.
    - Verified `drawArraysInstanced` is used instead of multiple `drawArrays` calls.

### 3. Unified Shader Functionality
- **Goal**: Ensure the unified shader program handles both Rect and Text types without program switching.
- **Method**: Inspect `WebGLRenderer.batchProgram` and verify it contains logic for both `a_instType` branches.
- **Result**: ✅ PASS
- **Evidence**: `tests/batch.spec.js` confirms `batchProgram` is initialized and active.

### 4. Performance Metrics (Simulated)
- **Goal**: Ensure CPU-GPU synchronization stalls are minimized via buffer orphaning.
- **Method**: Code audit of `ui/webgl/buffers.js` and `ui/webgl/renderer.js`.
- **Result**: ✅ PASS
- **Evidence**: `updateInstanceBuffer` correctly uses `bufferData(..., null)` before `bufferSubData` for orphaning.

## Observations
- The `webgl-active` class is correctly required for rendering to commence, preventing waste when WebGL is not needed.
- The `getActiveDisplayElement` correctly identifies elements for the "hugging" pattern in both standard and scientific modes.
- The atlas correctly caches glyphs, preventing redundant SDF generation.

## Final Verdict
The instanced batch rendering system is fully operational and meets all performance requirements for REQ-WGL-05.
