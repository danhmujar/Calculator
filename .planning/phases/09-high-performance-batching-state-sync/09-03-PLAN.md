# Plan: 09-03-PLAN.md — Instanced Batch Rendering

**Phase:** 09 - High-Performance Batching & State Sync
**Focus:** Minimizing draw calls through hardware instancing.

## Goal
Implement instanced rendering for common UI components (buttons, rows, text characters) to allow drawing many objects in a single WebGL command.

## Requirements
- **REQ-WGL-05**: Batch Rendering (100+ items).

## Success Criteria
1.  **Instanced Shaders**: Vertex shaders accept instanced attributes (rect, color, opacity, glyph ID).
2.  **Attribute Binding**: `vertexAttribDivisor` is used for per-instance data.
3.  **Single Draw Call**: 100+ scientific rows are rendered in 1-2 `drawArraysInstanced` calls.
4.  **Verifiability**: Chrome Performance Profiler shows a significant reduction in "Draw" events and CPU execution time.

## Technical Strategy
-   Use `vertexAttribDivisor(index, 1)` for per-instance properties.
-   Implement `ui/webgl/buffers.js` helper for updating instanced buffers using `bufferSubData` or orphaning.
-   Unify primitive and text rendering where possible or batch them in large sequences.
-   Store instance data in a compact format (float32 array) and transfer once per frame.
