| Test Case | ID | Status | Notes |

## Test 01: Basic Evaluation Success
**Action:** Call `CalculatorService.evaluate('2+2')` and `CalculatorService.evaluate('sqrt(144)')`.
**Expected:** `4` and `12`.

## Test 02: Security: Block AccessorNode
**Action:** Call `CalculatorService.evaluate('[].constructor')`.
**Expected:** `null`.

## Test 03: Security: Block High-Risk Functions
**Action:** Call `CalculatorService.evaluate('evaluate("2+2")')`.
**Expected:** `null`.

## Test 04: Security: Block Globals
**Action:** Call `CalculatorService.evaluate('window')`.
**Expected:** `null`.

## Test 05: Percentage Calculation Logic
**Action:** `calculatePercentage('type1', 10, 50)` and `calculatePercentage('type2', 20, 500)`.
**Expected:** `20` and `100`.

## Test 06: Error Handling
**Action:** `evaluate('10/0')` and `evaluate('invalid + expression')`.
**Expected:** `null` and `null`.
