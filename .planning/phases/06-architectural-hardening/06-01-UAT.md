| Test Case | ID | Status | Notes |
| :--- | :--- | :--- | :--- |
| **Lazy Shallow Cloning (O(1) reads)** | UAT-01-01 | [x] PASS | Confirmed `getState()` returns identical reference for no-op. |
| **Structural Sharing** | UAT-01-02 | [x] PASS | Unchanged branches maintain reference equality (e.g., `transient` branch remains identical when `persistent` is modified). |
| **State Segmentation (Persistence)** | UAT-01-03 | [x] PASS | Only `persistent` state is saved to `localStorage`. |

| **Batching Notifications** | UAT-01-05 | [x] PASS | Multiple updates in a `batch` trigger exactly one subscriber notification. |

## Test 01: Lazy Shallow Cloning (O(1) reads)
**Action:** Initialize `Store`, get state twice, and check if they are identical.
**Expected:** `state1 === state2`

## Test 02: Structural Sharing
**Action:** Modify `state.persistent.theme`, check if `state.transient` reference remains identical.
**Expected:** `stateBefore.transient === stateAfter.transient`

## Test 03 & 04: State Segmentation
**Action:** Modify `persistent.theme` and `transient.currentValue`, wait for save, and check `localStorage`.
**Expected:** `localStorage` contains `theme` but not `currentValue`.

## Test 05 & 06: Batching
**Action:** Update multiple properties within `store.batch(() => { ... })`.
**Expected:** Only 1 subscriber call and 1 `localStorage` write.

## Test 07: Array Structural Sharing
**Action:** Modify an object in state, check if an unrelated array reference remains identical.
**Expected:** `stateBefore.array === stateAfter.array`
