<objective>
Refactor the theme extraction and rendering loop to support smooth transitions and eliminate layout thrashing.

Purpose: The WebGL rendering loop currently calls `getComputedStyle` on every frame via `getThemeUniforms()`, causing severe performance degradation. This plan implements a `ThemeTransitionManager` to cache colors and interpolate them over ~400ms using a Quadratic Out easing function.
Output: An optimized `services/theme.js` and `ui/webgl/renderer.js` that smoothly transition background aurora colors.
</objective>
