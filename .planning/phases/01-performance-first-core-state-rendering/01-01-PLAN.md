  <action>
    Create a `Store` class that implements the PubSub pattern:
    - `constructor(initialState)`: Initialize state and empty subscribers array.
    - `getState()`: Returns a deep copy of current state.
    - `setState(updates)`: Merges updates into current state and notifies subscribers.
    - `subscribe(callback)`: Adds a callback to subscribers array. Returns an unsubscribe function.
    - Add a private method/subscriber for `localStorage` persistence:
      - Use `JSON.stringify` to save state under key `interactiveCalcState`.
      - Implement 500ms debounce for `localStorage.setItem` to avoid performance hits during rapid input.
    - Export an instance of `Store` with the default calculator state as specified in RESEARCH.md and existing app.js logic.
