## Gaps Found & Fixed
1. **MathLive Font Path:** Found that MathLive was failing to load fonts in the test environment because it was defaulting to a Vite-proxied `node_modules` path that returned 404/OTS errors.
    - **Fix:** Explicitly set `window.MathfieldElement.fontsDirectory = '/Calculator/fonts/'` in `ui/uimanager.js` during initialization and mode switch.
2. **Performance Threshold:** Initial 10 FPS threshold was too tight for some headless runs.
    - **Fix:** Relaxed to 5 FPS for the stress test while observing actual performance ~18 FPS.
